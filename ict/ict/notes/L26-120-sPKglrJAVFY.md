## Concepts

### Order Block (Hierarchical Parent/Child Relationship)
- **Kind:** definition / rule (heavily refined)
- **What ICT says:** An order block is a candlestick formed at a key level (often at the bottom of a fair value gap or at a gradient level). Order blocks have a hierarchy: a parent order block is one that is laying on top of a gradient level (quadrant or octant). A propulsion block is a child order block that trades down into a parent order block; it need not be on a gradient level because it "borrows" the parent's discount sensitivity. "This candlestick right here is part of this overall run to this liquidity... If this wasn't a run just to get here, dropping back down there, that would have been used to go long. This would have been a bullish fair value gap. But because we're part of a bearish narrative, this becomes a mitigation block."
- **How to identify:** Look at where a candlestick is positioned relative to: (1) a gradient level (quadrant or octant), (2) a fair value gap, (3) prior price action. If laying on a gradient level and used for entry, it's an order block. If it's part of a run to liquidity, it can be a mitigation block instead.
- **How to use:** Parent order blocks anchor stop losses and define turning points. Propulsion blocks validate continuation and provide adding-in opportunities. Mitigation blocks define the rejection of a directional move and often precede reversal.
- **Example in this video:** NQ 1m, March 13: opening price at 9:30 becomes an order block (laying on the upper quadrant of RTH opening range gap). Later price uses it as a mitigation block, changing its function based on subsequent order flow. "That candlestick right here that starts these two down close handle. This is the parent order block. Why? Because it's laying over top of... the quadrant level... of the regular trading hours opening range gap."
- **Timestamps:** [0:30:25](https://youtu.be/sPKglrJAVFY?t=1825), [0:31:58](https://youtu.be/sPKglrJAVFY?t=1918), [0:32:45](https://youtu.be/sPKglrJAVFY?t=1965), [0:34:18](https://youtu.be/sPKglrJAVFY?t=2058)
- **Nuance / caveats / changes:** Order blocks change their state based on order flow context; a down-close candle is NOT automatically a bullish order block. "Just because you see a down close candle doesn't make it a bullish order block." The gradient level anchoring is critical; without it, the level lacks validity.

### Propulsion Block
- **Kind:** definition / entry model
- **What ICT says:** A candlestick that trades down into a parent order block (which is laying on a gradient level). In a bullish move, this is a "buy side delivery going to buy side liquidity." It need not be on a gradient level itself because it borrows the parent order block's discount sensitivity. Validates continuation in the intended direction.
- **How to identify:** Look for a candlestick that trades into (not just near) a prior order block; measure if it's a valid entry point based on order flow.
- **Example in this video:** NQ 1m: "This is a valid propulsion block when it's bullish or buy side delivery going to buy side liquidity. This cannot go down to half of this range. It clearly didn't do that. The only thing it did was what? Use the opening. On this candlestick right there which is a change in the state of delivery."
- **Timestamps:** [0:32:45](https://youtu.be/sPKglrJAVFY?t=1965)
- **Nuance / caveats / changes:** Distinct from parent order block; it's a child that validates the parent's function.

### Mitigation Block
- **Kind:** definition
- **What ICT says:** An order block that, due to the bearish order flow context, becomes a rejection point rather than an entry point. Instead of facilitating a bullish move, it gets used and then prices collapse, indicating the market is mitigating the buy-side run. "Since it's a run just for liquidity, this order block can't... be part of a buying scenario. So, what is it going to be? Mitigation block."
- **How to identify:** An order block that is taken out (price runs through it to take buy-side liquidity above), but then price reverses aggressively lower, rejecting the move.
- **Example in this video:** NQ 1m, March 13: the order block at the upper quadrant is mitigated; price runs up to take liquidity, then reverses sharply lower, validating the bearish narrative.
- **Timestamps:** [0:30:25](https://youtu.be/sPKglrJAVFY?t=1825), [0:38:18](https://youtu.be/sPKglrJAVFY?t=2298)
- **Nuance / caveats / changes:** Function of an order block is determined by subsequent price action, not its formation. Context is king.

### Gradient Levels (Octants & Quadrants)
- **Kind:** definition / reference levels
- **What ICT says:** The opening range gap (RTH or new week opening gap) is divided into gradient levels using fibonacci divisions: quadrants (four divisions: 0.25, 0.50, 0.75, 1.0) and octants (eight divisions: 0.125, 0.25, 0.375, 0.50, 0.625, 0.75, 0.875, 1.0). These levels act as anchors for order blocks, propulsion blocks, and all intraday targeting. "Every time it gives me an opportunity to trade at the consequent crush zone just close to it, I'm going to add one more. And I built a position of four micro contracts." All his entries and scalps use these gradient levels as reference points.
- **How to identify:** Calculate the opening range gap (high - low of the gap); divide by 4 (quadrants) or 8 (octants); mark them on the chart.
- **How to use:** As anchors for order block placement, entry points, stop losses, and target levels. ICT's instruction: "Everything has to be anchored to these gradient levels. Otherwise, you're guessing."
- **Example in this video:** NQ 1m, RTH gap at 9:30 has gradient levels marked; every major turning point uses a quadrant or octant level.
- **Timestamps:** [0:24:03](https://youtu.be/sPKglrJAVFY?t=1443), [0:30:25](https://youtu.be/sPKglrJAVFY?t=1825), [0:34:18](https://youtu.be/sPKglrJAVFY?t=2058), [0:43:09](https://youtu.be/sPKglrJAVFY?t=2589)

### Buy-Side Inefficiency (BISI) / Sell-Side Inefficiency (SIBI)
- **Kind:** definition
- **What ICT says:** BISI (buy-side inefficiency, sell-side inefficiency) is when there is a separation between a candlestick's close and the next candle's open on the buy side (or sell side), forming a gap. This is different from a volume imbalance. When there's a volume imbalance on one side OR both sides of an inefficiency, you must note it—these are distinct details. "If it would have had a volume imbalance on the high end, that's a suspension block. It's not suspension block. They're all treated the same way. Differences is when there's a inefficiency that has a volume imbalance in one side or both, you have to note it."
- **How to identify:** Look at the close of one candle and the open of the next; if there's a gap (close lower than open, or open higher than close), that's an inefficiency. If the bodies also show a volume imbalance, note both.
- **Example in this video:** NQ 1m: "That candlestick's low. 24,834 quarter. That is a SIBI. I'm sorry, it's a BISI. Buy side and sell side inefficiency."
- **Timestamps:** [0:26:28](https://youtu.be/sPKglrJAVFY?t=1588)
- **Nuance / caveats / changes:** BISI/SIBI must be distinguished from volume imbalances; both can be present, or only one.

### Volume Imbalance
- **Kind:** definition
- **What ICT says:** A gap between a candlestick's close and the next candle's open, where the bodies themselves show separation (one candle's close does not align with the next candle's open). Distinguished from BISI/SIBI by the fact that it shows a clear body separation. "You're getting more detail, okay? And it's not changing. Nothing's changing about it."
- **Example in this video:** "The close on that candlestick right there? 24,828 half. Okay, or 0.50. The open on this candlestick is 24,828.75. So, it's 1 quarter of a handle higher. That's a volume imbalance."
- **Timestamps:** [0:26:28](https://youtu.be/sPKglrJAVFY?t=1588)
- **Nuance / caveats / changes:** Details matter; noting volume imbalances makes the difference between profitable and unprofitable trading.

### Inversion Fair Value Gap (Revisited in Order Flow Context)
- **Kind:** entry model
- **What ICT says:** When price trades into an FVG area that was originally bullish (would have been bullish if the narrative was bullish), but because the order flow is bearish, it becomes an inversion FVG. The FVG itself doesn't change; the context does. "This gap would have been bullish if order flow was bullish and the narrative was bullish, but we're not. So, this needs to become what? Inversion. So it becomes an inversion fair value gap."
- **How to identify:** Look at a fair value gap; if price is trading up into it but bodies are rejecting and staying below a certain level, and your bias is bearish, it's an iFVG.
- **Example in this video:** NQ 1m: Thursday's first-presented FVG would have been bullish, but because bodies rejected and order flow was bearish, it flipped to an iFVG for the short setup.
- **Timestamps:** [0:35:54](https://youtu.be/sPKglrJAVFY?t=2154)
- **Nuance / caveats / changes:** Context determines whether an FVG is bullish or inverted; the level itself is objective.

### Change of State of Delivery (CISD)
- **Kind:** rule
- **What ICT says:** When price action shifts from one delivery context to another (e.g., from seeking buy-side liquidity to seeking sell-side), that's a change of state. It's often marked by an opening price that becomes an order block, shifting the entire narrative. "Change of state of delivery, it opens up here. And trades down right to it by a tick more. Below it and then comes here."
- **Example in this video:** NQ 1m: the 9:30 opening creates a shift from the prior structure.

### Consequent Encroachment (Wick Midpoint)
- **Kind:** definition / targeting

## Glossary candidates

`ORDER BLOCK` — A candlestick at a key level (often a gradient level). Parent order blocks anchor on gradient levels; propulsion blocks trade into them; mitigation blocks are rejected. Function determined by order flow context.

`PROPULSION BLOCK` — A candlestick that trades into a parent order block, validating continuation; borrows the parent's discount sensitivity.

`MITIGATION BLOCK` — An order block that is taken out (buy-side run) but then price reverses, rejecting the move; marks a directional shift.

`GRADIENT LEVELS` — Fibonacci divisions of opening range gaps: quadrants (4 divisions) and octants (8 divisions); all order flow is anchored to these.

`BISI / SIBI` — Buy-side inefficiency / Sell-side inefficiency; gap between candle close and next candle open without necessarily a volume imbalance body separation.

`VOLUME IMBALANCE (VIM)` — Clear body separation between consecutive candlesticks; one close does not align with next open.

`CHANGE OF STATE OF DELIVERY (CISD)` — Shift in order flow context; often marked by opening price becoming an order block and narrative shifting.

`INVERSION FVG` — Fair value gap that is used in opposite direction due to order flow context; would be bullish if context was bullish, but becomes iFVG when bearish.

`MACRO TIME` — Specific times (8:00, 9:00, 9:30 ET) when algorithmic execution is predictable; liquidity runs align with these.

`MICRO PROGRESSION` — Discipline of starting small (micro contracts), earning skill, and graduating to larger leverage only after emotional mastery.
